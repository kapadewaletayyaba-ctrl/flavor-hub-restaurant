# 🍽️ FlavorHub - Restaurant Web Application

**FlavorHub** is a modern, responsive, and full-featured restaurant web application built as part of a Web Development Internship project. The platform provides a smooth user experience for online menu browsing, interactive food ordering, table reservations, customer reviews, dark mode toggling, and live operating status updates.

---

## ✨ Features & Highlights

- 📱 **Fully Responsive Design**: Optimized for seamless viewing across desktops, tablets, and mobile devices.
- 🍔 **Interactive Menu & Dietary Filters**: Browse items by categories (*Appetizers, Soups & Salads, Main Course, Pizzas, Burgers, Desserts, Beverages*) and filter by dietary tags (*Vegetarian, Non-Vegetarian, Vegan, Gluten-Free, Spicy, Chef's Special*).
- 🕒 **Real-Time Operating Hours & Status**: Live calculation displaying whether the restaurant is currently **Open** or **Closed** based on local time.
  - **Mon – Thu**: 11:00 AM – 10:00 PM
  - **Fri – Sat**: 11:00 AM – 11:00 PM
  - **Sunday**: 12:00 PM – 9:00 PM
- 🛒 **Cart & Food Ordering System**: Interactive cart drawer to add items, view subtotal, and simulate checkout.
- 📅 **Table Reservation System**: Online booking with date/time pickers and guest constraints.
- 🌙 **Dark Mode Toggle**: Effortless switching between light and dark themes.
- 📸 **High-Quality Food Gallery**: Visual showcase of dishes, interior ambiance, and special offers.

---

## 🛠️ Technologies Used

- **Backend**: Python 3, Flask framework
- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Icons & Styling**: Font Awesome icons, Google Fonts
- **Data Management**: In-memory Python structures & browser `localStorage` (No database setup required)
